# qt6530
Graphical Terminal emulator 6530 based on libvt6530
uses QT6 and OpenSSH libraries, linux and windows compatible

added features

Telnet support compatible with Nonstop TELSERV product
SSH support (OpenSSH libraries) compatible with Nonstop SSH Server with 6530 terminal specifications protocol
Conversional and block mode working 
Windows and Linux

Tested on
Oracle Linux 10 
Windows 11

Documentation used
6530 Programmer's Guide

Tools used 
MSYS (windows)
qtcreator
inno setup(windows)
